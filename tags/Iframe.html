Iframe tag ("<iframe>"....."</iframe>") - [Both Opening & Closing tags required]

Description:- The <iframe> (Inline Frame) tag is used to embed another separate HTML document within the current document. It creates a nested browsing context, allowing external web pages, YouTube videos, maps, and interactive widgets to be displayed directly on your page.

Discontinued Alternatives & Security Best Practices:

• Discontinued Tags: The old HTML4 <frameset>, <frame>, and <noframes> tags are completely obsolete in HTML5. <iframe> is the sole standard for framed content.
• Security (sandbox attribute): Always add the sandbox attribute when embedding untrusted content to prevent malicious scripts, popups, and automatic form submissions.
• Performance (loading="lazy"): Modern browsers support loading="lazy" on iframes so offscreen embedded frames don't slow down initial page loads!

Key Attributes:-

  • src (Required) :- The URL of the page or video to embed.
  • title (Crucial for Accessibility) :- Explains what the frame contains to screen readers.
  • loading="lazy" :- Defers loading the iframe until the user scrolls near it.
  • sandbox :- Enables strict security restrictions (disables scripts, forms, and popups by default).
  • allowfullscreen :- Enables full-screen mode (essential for YouTube/Vimeo video embeds).

Use cases:-

  • Embedding YouTube/Vimeo video players.
  • Embedding interactive Google Maps locations.
  • Displaying external payment gateways or third-party ad banners securely.
