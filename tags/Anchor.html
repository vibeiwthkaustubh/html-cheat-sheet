1.Anchor Tag ("<a>"....."</a>") - [Both Opening & Closing tags required]

Description:- It is used to create the hyperlinks. If you wish to add an external link in a web page you can use anchor tag to do so.

Example:- If you will click on the Example you will go to the geekforgeeks wesites anchor tag page.

Attributes:-

  1. Target :- It tells the browser whether to open the link in the same tab, a new tab, or in a specific frame/iframe.
      Values and their use case :-
    • _Blank :- Opens the link in a new tab/window
    • _self (Default) :- Opens the link in the same tab/window
    • _parent :- Opens the link in the full window, breaking out of all frames
    • _top :- Opens the link in a specific named frame/iframe
  2. Title :- One can put a value which will will appear while hovering the mouse on the link. For example hover the mouse on the Example link
  3. Download :- The download attribute in the anchor tag is used to tell the browser: "Instead of opening this link, download the file."
    • The value inside this will be the name for the file that will be shown after downloading.

Use case :-

  • Linking to another webpage
  • Linking to a section within the same page (internal link)
  • Linking to an email address
  • Linking to a phone number (mobile-friendly)
  • Downloading a file directly
