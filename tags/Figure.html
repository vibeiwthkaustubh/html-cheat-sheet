Figure & Figcaption tags ("<figure>", "<figcaption>") - [Both Opening & Closing tags required]

Description:- The <figure> tag specifies self-contained content, like illustrations, diagrams, photos, code listings, or charts. The <figcaption> tag defines an optional caption or legend for that figure. If removed from the main flow, the document flow remains intact.

<figcaption> vs <caption> Difference:

• <caption> is strictly used as the title for a data <table>.
• <figcaption> is exclusively used inside a <figure> (can be placed as the first or last child).
• Using <figure> is vastly superior to grouping an image and paragraph inside a generic <div> because assistive technologies explicitly identify the caption as linked to that visual media.

Placement Rules:-

  • <figcaption> must be either the first child or the last child of the <figure> element.

Use cases:-

  • Photos, artwork, and infographics in articles.
  • Code snippets that have explanatory figure labels.
  • Mathematical equations, charts, and scientific diagrams.
