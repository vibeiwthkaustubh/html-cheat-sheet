Colgroup tag ("<colgroup>"....."</colgroup>") - [Both Opening & Closing tags required]

Description:- The <colgroup> tag is used to specify a group of one or more columns in an HTML table for structural grouping and formatting. It must appear directly inside a <table>, after any <caption> element and before any <thead>, <tbody>, <tfoot>, or <tr> tags.

Standards & Modern Usage Note:

A <colgroup> can either hold individual <col> elements or use the span attribute directly on the <colgroup span="2">. Like <col>, obsolete HTML4 alignment attributes (align, valign) have been discontinued in HTML5 in favor of CSS.

Example:- In the table below, columns are grouped into personal details and scores:

First Name Last Name Grade
Kaustubh Singh A+
Rahul Kumar A

Attributes:-

  • span :- Specifies the number of columns in the group (default is 1).

Use cases:-

  • Grouping related data columns visually in financial and performance reports.
  • Applying batch background colors or borders to multiple table columns at once.
