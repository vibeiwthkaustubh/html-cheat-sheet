Button tag ("<button>"....."</button>") - [Both Opening & Closing tags required]

Description:- The <button> tag defines an interactive, clickable button. Unlike older input buttons, the <button> element can contain rich content inside it, such as text, icons, images, or formatted HTML elements.

Keyboard Shortcuts & Accessibility Best Practices:
  • Native Enter Submission: When typing inside any input field in a form, hitting the Enter key automatically submits the form by activating the first <button type="submit"> (known as Implicit Submission in HTML).
  • The accesskey Attribute: You can assign a custom keyboard shortcut using the accesskey attribute (e.g. accesskey="s" for Submit and accesskey="r" for Reset). On Windows browsers, press Alt + s (or Alt + Shift + s in Chrome) to trigger that button directly.
  • Why Enter itself cannot be an accesskey value: The HTML specification specifies that accesskey only takes single characters/letters (like s, r, 1). Special keys like Enter are handled natively by the browser for forms!

Attributes:-

  • type :- Specifies the button behavior:
    • submit: Submits form data to the server (default behavior inside forms; triggered natively by the Enter key).
    • reset: Resets all controls in the form back to their initial values.
    • button: General clickable button with no default behavior (ideal for JavaScript).
  • accesskey :- Assigns a shortcut key to activate or focus the button (e.g. accesskey="s" activated via Alt+S).
  • disabled :- Disables the button, preventing click events and keyboard focus.
  • name & value :- The name and value submitted with the form when clicked.
  • form :- Associates the button with a specific <form> ID, even if placed outside the form tags.

Use cases:-

  • Submitting forms securely to backend servers.
  • Resetting complex multi-field forms with a single click or shortcut.
  • Enabling keyboard accessibility for power users with accesskey.
  • Opening modals, popups, dropdown menus, and navigation drawers.
