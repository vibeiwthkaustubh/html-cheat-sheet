Caption tag ("<caption>"....."</caption>") - [Both Opening & Closing tags required]

Description:- The <caption> tag is used to define a title or explanatory heading for an HTML <table>. By rule, it must be inserted immediately after the opening <table> tag (before any <thead>, <tbody>, or <tr> elements), and each table can have only one caption.

Standards & Community Comparison:
  • <caption> vs <figcaption>: Use <caption> exclusively for data tables. For images, charts, or illustrations inside a <figure> tag, use <figcaption> instead.
  • Discontinued Attribute (align): In older HTML4, the <caption align="bottom|top"> attribute was used for positioning. In modern HTML5, align is obsolete. Use the modern CSS property caption-side: top | bottom; instead.
  • Accessibility Impact: Never replace <caption> with a standard <h3> above the table. Screen readers announce the <caption> automatically when users navigate to a table, letting them know what data they are about to read.

Example:- Below is a table displaying monthly student test scores with a styled <caption> placed at the top:

Quarterly Student Assessment Report (2026)
Roll No Student Name Subject Grade
101 Kaustubh Singh Web Development A+
102 Rohan Sharma Python Programming A
103 Priya Patel Database Systems A+

Attributes:-

  • Global Attributes :- The <caption> tag supports all global attributes like class, id, and style.
  • Obsolete Attributes :- The historical align attribute (top, bottom, left, right) is deprecated. Use CSS properties caption-side: bottom; and text-align: center; instead.

Use cases:-

  • Labeling financial statements, balance sheets, and invoice tables.
  • Providing accessible descriptions for tabular data in scientific and academic reports.
  • Giving screen reader users immediate context before navigating through large datasets.
  • Positioning titles at the top or bottom of data matrices using modern CSS.

   </tr>
  </tbody>

 </ul>
