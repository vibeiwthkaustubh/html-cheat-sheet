Area tag (<area>) - [Void Tag / Self-Closing (No Closing tag required)]

Description:- The <area> tag in HTML is used to define a specific clickable area (hotspot) inside an image map. It must be placed inside a <map> element, When you use the img tag to import the image on which you want to make the clickable area make sure to use a attribite called usemap ="#Name" inside the image tag for refrence.

Example:- Here is an image of the superheros of the comic line called Avengers. if you click on any superhero's face a page will open consisting of the info about that superhero.

Attributes:-

  1. Shape :- Defines the shape of the clickable area it can be
    • Circle
    • Rectangle
    • Polygon
  2. coords :- Defines the exact pixel coordinates of the clickable region inside an image map. Its meaning depends on the shape you specify
  3. href :- tag) specifies the URL or resource that the clickable region will link to.
  4. alt :- tag provides alternative text that describes the clickable region of an image map.

Use cases:-

  • Interactive Diagrams
  • Geographic Maps
  • Infographics / Floor Plans
