Description List tags ("<dl>", "<dt>", "<dd>") - [Both Opening & Closing tags required]

Description:- The <dl> (Description List) element encloses a list of term-description groups. It uses <dt> to specify a term or name, and <dd> to provide the definition, description, or value of that term.

Semantic Evolution Note:

In HTML4, <dl> was strictly called a "Definition List". In HTML5, it was broadened into a "Description List", making it semantically appropriate for any key-value pair, metadata lists, author info, FAQs, and product specs, not just dictionary definitions.

Example:- Web Technology Glossary created with <dl>, <dt>, and <dd>:

HTML
HyperText Markup Language - the standard language for creating the structure of web pages.
CSS
Cascading Style Sheets - used to style layout, colors, and visual presentation.
JavaScript
A lightweight, interpreted programming language that adds interactivity and logic to websites.

Elements in this Group:-

  • <dl> :- Wrapper container for the entire description list.
  • <dt> :- Description Term (the word, question, or key).
  • <dd> :- Description Details (the explanation, answer, or value).

Use cases:-

  • Creating technical glossaries and dictionary definitions.
  • Building FAQ (Frequently Asked Questions) sections.
  • Displaying metadata key-value pairs (e.g. Director: Christopher Nolan, Release: 2026).
