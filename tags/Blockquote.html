Blockquote tag ("<blockquote>"....."</blockquote>") - [Both Opening & Closing tags required]

Description:- The <blockquote> tag is used to represent an extended section of quoted text that is taken from another external source or author. Browsers traditionally render blockquotes with an indentation on both sides, which can be enhanced with CSS to give a modern editorial quote look.

Example:- The block below is rendered inside a blockquote element:

"Your time is limited, so don't waste it living someone else's life. Don't be trapped by dogma - which is living with the results of other people's thinking."

- Steve Jobs, Stanford Commencement Address

Attributes:-

  • cite :- Specifies the source URL of the quotation. While this URL is not directly visible to users on the screen, search engines and accessibility tools use it for citation verification.

Use cases:-

  • Featuring customer testimonials and reviews on business websites.
  • Quoting expert opinions, research findings, or book excerpts in blog posts.
  • Presenting speech transcripts and famous quotes in editorial articles.
  • Improving SEO and semantic accessibility for referenced external content.
