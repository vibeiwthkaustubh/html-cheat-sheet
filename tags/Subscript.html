Subscript & Superscript tags ("<sub>", "<sup>") - [Both Opening & Closing tags required]

Description:- The <sub> tag defines subscript text (rendered half a character below the baseline with a smaller font). The <sup> tag defines superscript text (rendered half a character above the baseline).

Semantic Usage Rule:

Both tags should only be used where the subscript or superscript notation conveys typographical meaning (chemical formulas, mathematical exponents, footnotes, or ordinal numbers like 1st). Do not use them for purely decorative vertical alignment - use CSS vertical-align instead.

Example:- Chemistry and Mathematics notation:

Chemical Formula for Water: H2O

Chemical Formula for Glucose: C6H12O6

Pythagorean Theorem: a2 + b2 = c2

Today is September 13th, 2026

Attributes:-

  • Global Attributes :- class, id, style.

Use cases:-

  • Chemical formulas (H2SO4).
  • Mathematical powers and exponents (x2).
  • Footnote references in academic papers [1]1.
  • Ordinal numbers (1st, 2nd, 3rd).
