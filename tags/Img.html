Img tag ("<img>") - [Void Tag / Self-Closing (No Closing tag required)]

Description:- The <img> tag is a void element used to embed images into an HTML document. Rather than inserting images directly into the markup, the browser uses the image path provided in the src attribute to fetch and display the graphic.

Mandatory Accessibility & Modern Performance Rules:

• The alt attribute is MANDATORY: Always specify descriptive alternative text for screen readers and when the image fails to load. For decorative images, use alt="".
• Prevent Cumulative Layout Shift (CLS): Always declare explicit width and height attributes on images so the browser reserves layout space before download.
• Modern Performance: Use loading="lazy" to defer offscreen image loading, and decoding="async" to decode off the main thread.
• Modern Multi-format Alternative: Use <picture> when serving next-gen AVIF/WebP formats with fallback PNG/JPEGs.

Example:- Image rendered with responsive max-width and alt text:

Rendered via <img src="The Avengers.jpg" alt="..." />

Attributes:-

  • src (Required) :- URL or relative path of the image.
  • alt (Required) :- Descriptive alternative text for screen readers and broken links.
  • width & height :- Aspect ratio and dimensions in pixels.
  • loading="lazy" :- Defers off-screen image loading until scrolled near.
  • decoding="async" :- Decodes image asynchronously to prevent UI freezing.

Use cases:-

  • Displaying photos, hero banners, product thumbnails, logos, and badges.
