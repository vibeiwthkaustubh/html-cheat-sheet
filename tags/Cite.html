Cite tag ("<cite>"....."</cite>") - [Both Opening & Closing tags required]

Description:- The <cite> tag is an inline semantic element used to define the title of a creative work (such as a book, article, poem, movie, song, painting, sculpture, TV show, or academic paper). Browsers display the contents of a <cite> tag in italics by default.

Crucial HTML5 Specification Rule:

In older HTML4, people sometimes wrapped an author's name in <cite>.
HTML5 Rule: The W3C/WHATWG specification states that an author's or person's name is NOT a creative work and must never be wrapped in <cite>. Only the title of the work belongs inside <cite>.
Correct: <cite>The Great Gatsby</cite> by F. Scott Fitzgerald
Incorrect: The Great Gatsby by <cite>F. Scott Fitzgerald</cite>

Example:- Examples of citing creative works correctly:

Book: Clean Code was written by Robert C. Martin.

Movie: Christopher Nolan directed Oppenheimer in 2023.

Song: Have you listened to Wishes by Talwinder?

Attributes:-

  • Global Attributes :- The <cite> tag supports all standard HTML global attributes including class, id, title, and style.

Use cases:-

  • Citing reference books, novels, and journals in articles and blogs.
  • Attributing quotes inside or alongside <blockquote> elements.
  • Referencing movies, games, theatrical plays, and musical albums in reviews.
  • Improving search engine indexing and bibliographic parsing of referenced works.
