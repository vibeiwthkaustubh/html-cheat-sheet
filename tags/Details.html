Details tag ("<details>"....."</details>") - [Both Opening & Closing tags required]

Description:- The <details> tag creates a native interactive disclosure widget from which the user can obtain additional information or expand/collapse content. The visible title of the widget is specified using the <summary> element.

Modern HTML5 Feature: Zero JavaScript Accordion!

Prior to HTML5, developers had to write custom JavaScript click listeners and CSS display toggles to build accordions and collapsible FAQs. The <details> element handles all of this natively in browser engine code, including keyboard space/enter toggling and screen reader accessibility!

What is HTML5?

HTML5 is the latest major revision of the HTML standard, bringing semantic tags, multimedia playback, native form validation, and APIs without plugins.

Why use semantic HTML tags?

Semantic tags clearly describe their meaning to both the browser and developer, improving accessibility, screen reader navigation, and SEO ranking.

Attributes:-

  • open :- Boolean attribute indicating whether the details are visible (expanded) on page load.

Use cases:-

  • Building interactive FAQs with zero lines of JavaScript.
  • Hiding spoiler text or detailed technical logs behind collapsible cards.
  • Collapsible navigation sidebars and nested folder views.
