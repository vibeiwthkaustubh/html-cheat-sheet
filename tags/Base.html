Base tag ("<base>") - [Void Tag / Self-Closing (No Closing tag required)]

Description:- The <base> tag is used to specify a default URL and a default target for all relative links and assets (like images, scripts, and stylesheets) in an HTML document. It must be written inside the <head> element, and an HTML document can contain at most one <base> element.

Example:- If you define a base URL, any relative link on the page will automatically combine with this base address instead of the current page location.

Simulated Demonstration:

Assume the head contains: <base href="https://www.example.com/assets/" target="_blank" />

Now, when you write: <a href="products.html">View Products</a>

The browser will automatically navigate to: https://www.example.com/assets/products.html in a new tab (because target="_blank" was set).

Attributes:-

  • href :- Specifies the base URL for all relative URLs in the document.
  • target :- Specifies the default target browsing context for all hyperlinks and forms on the page (such as _blank, _self, _parent, or _top).

Use cases:-

  • Setting a centralized base domain so you don't have to repeat long absolute paths for every image or link.
  • Opening all page links in a new tab by default using target="_blank" without needing to write it on every anchor tag.
  • Moving files between local staging and CDN servers by simply changing a single base URL.
  • Handling client-side routing and relative subdirectories cleanly in complex web applications.

<html lang="en">
 <head>
  <meta charset="UTF-8" />
  <title>Base Tag Example</title>
  <!-- Base tag specifying default URL and default target -->
  <base href="https://www.example.com/assets/" target="_blank" />
 </head>
 <body>
  <header>
   <h1>Base tag</h1>
   <p>Learn tags with description, use cases, and examples</p>
  </header>

  <main>
   <h2>Base tag ("&lt;base&gt;")</h2>

    URL and target for all relative links in the document.
   </p>
   <p>
    <strong>Example:-</strong>
    Clicking the link below will resolve to: https://www.example.com/assets/products.html
   </p>

   <!-- Relative link resolved against base href -->
   <a href="products.html">View Products (Opens in new tab)</a>

   <h3>Attributes:-</h3>
   <ul>
    <li>
     <strong>href :-</strong> Specifies the base URL for all relative URLs.
    </li>
    <li>
     <strong>target :-</strong> Specifies the default target window/tab.
    </li>
   </ul>

   <p><strong>Use cases:-</strong></p>
   <ul>
    <li>Setting a centralized domain for all relative URLs.</li>
    <li>Defaulting link behavior to open in a new tab.</li>
    <li>Managing paths when deploying to CDNs.</li>
   </ul>
  </main>
 </body>
</html>
