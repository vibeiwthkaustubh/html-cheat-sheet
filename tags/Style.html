Style tag ("<style>"....."</style>") - [Both Opening & Closing tags required]

Description:- The <style> tag is used to define internal CSS (Cascading Style Sheets) style rules for an HTML document. It must be placed inside the <head> element, and governs the colors, typography, layout, and visual presentation of all elements on the page.

Best Practice: External vs Internal Styles:

While <style> is great for single-page cheat sheets, email templates, or critical CSS, large production websites prefer linking external stylesheets via <link rel="stylesheet" href="style.css"> so the CSS is cached across all pages, speeding up navigation!

Example:- You are looking at the result of an internal <style> tag right now on this page!

All margins, font families, colors, and borders on this page are powered by the <style> tag inside the head!

Attributes:-

  • media :- Specifies which media the styles apply to (e.g. screen, print).

Use cases:-

  • Injecting critical above-the-fold CSS for fast Largest Contentful Paint (LCP).
  • Styling HTML email templates where external stylesheets are blocked.

Complete code for the Style tag section

<head>
 <style>
  body {
   background-color: white;
   font-family: Arial, sans-serif;
  }
  h1 {
   color: #333;
  }
 </style>
</head>
