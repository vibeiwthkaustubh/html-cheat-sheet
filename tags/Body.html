Body tag ("<body>"....."</body>") - [Both Opening & Closing tags required]

Description:- The <body> tag defines the main body of an HTML document. It encloses all the visible contents of the web page, including headers, headings, paragraphs, images, tables, lists, audio, video, and hyperlinks. Every HTML document must have exactly one <body> element, and it is placed directly below the <head> tag inside the root <html> element.

Example:- The entire visible page you are looking at right now is located inside the <body> tag. Here is a visual representation of how the document is structured:

Document Layout Hierarchy:
<html> (The Root Element)
<head> - Contains invisible metadata, titles, styles, and scripts.
<body> - Contains ALL visible components (Header, Main, Article, Footer, etc.).

Attributes:-

  • Global Attributes :- The <body> tag supports all global HTML attributes such as class, id, style, and lang (often used to toggle themes like <body class="dark-theme">).
  • Window Event Attributes :- Can trigger scripts upon page actions, such as onload (fires when the page finishes loading), onresize (fires when the window is resized), and onscroll.

Use cases:-

  • Containing the entirety of a website's renderable UI and contents.
  • Setting default page-wide CSS rules such as font family, base text color, and background styling.
  • Implementing light/dark mode toggles by adding state classes to the body tag.
  • Executing JavaScript code as soon as the DOM and assets finish loading using the onload event.

Complete code for the Body tag section

<!doctype html>
<html lang="en">
 <head>
  <meta charset="UTF-8" />
  <title>Page Title</title>
 </head>

 <!-- The body tag encapsulates all visible elements -->
 <body class="light-mode">
  <header>
   <h1>Welcome to My Website</h1>
  </header>

  <main>
   <p>This is visible text rendered inside the body element.</p>
  </main>

  <footer>
   <p>&copy; 2026 Kaustubh's HTML Guide</p>
  </footer>
 </body>
</html>
