Svg tag ("<svg>"....."</svg>") - [Both Opening & Closing tags required]

Description:- The <svg> tag defines a container for Scalable Vector Graphics (SVG). Unlike raster image formats (like JPEG or PNG) that lose quality and become pixelated when zoomed in, SVG is XML-based vector graphics that scales infinitely to any resolution without loss of crispness.

Inline SVG Advantages:

Embedding SVG directly into HTML allows you to control SVG colors, strokes, and animations directly with CSS (e.g. fill: #4caf50; on hover) and interact with individual SVG paths using JavaScript!

Example:- Pure Scalable Vector Graphic drawn with SVG:

Infinitely scalable vector circle and star.

Key Elements inside <svg>:-

  • <circle>, <rect>, <polygon>, <line>, <path>.
  • viewBox :- Defines coordinate system aspect ratio.

Use cases:-

  • Crisp UI icons that adapt to high-DPI Retina screens.
  • Company logos and brand graphics.
  • Interactive charts, graphs, and maps (D3.js).
