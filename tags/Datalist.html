Datalist tag ("<datalist>"....."</datalist>") - [Both Opening & Closing tags required]

Description:- The <datalist> tag contains a set of predefined <option> elements that provide an "autocomplete" dropdown list for an associated <input> element. Users can either type their own custom value or pick from the recommended suggestions.

<datalist> vs <select> Comparison:

A <select> dropdown strictly forces the user to choose only from predefined options. In contrast, an <input list="..."> paired with a <datalist> gives users the best of both worlds: autocomplete suggestions while still allowing free text input. It replaces complex, heavy third-party JavaScript autocomplete plugins.

Attributes:-

  • id (Required) :- Must match the list attribute value on the corresponding <input>.

Use cases:-

  • Country/city selection with search-as-you-type assistance.
  • Search bars with top trending search suggestions.
  • Form fields where standard suggestions are helpful but custom values are allowed.
