Br tag ("<br>") - [Void Tag / Self-Closing (No Closing tag required)]

Description:- The <br> (Line Break) tag produces a single line break in text (carriage return). It is a void element (empty tag), meaning it has no closing tag and does not wrap content.

Best Practice & Modern Alternatives Note:

The HTML community strongly advises never using multiple <br> tags to create spacing or layout margins between elements. Doing so causes accessibility issues for screen readers.
Modern Alternative: For vertical spacing, wrap content in separate <p> or <div> elements and use CSS margin-bottom or CSS Grid/Flexbox gap. The obsolete attribute <br clear="..."> has also been discontinued in favor of CSS clear: both;.

Example:- The <br> tag is strictly intended where the line break is an intrinsic part of the text itself, such as in poems, lyrics, or addresses:

Roses are red,
Violets are blue,
HTML gives structure,
And CSS styles it too!

Attributes:-

  • Global Attributes :- The <br> tag supports standard global attributes like class, id, and style.
  • Obsolete Attributes :- The historical clear attribute (<br clear="all">) is deprecated and removed in HTML5. Use CSS clear property instead.

Use cases:-

  • Formatting poems, haikus, or song lyrics without creating separate paragraphs.
  • Writing street addresses inside the <address> tag.
  • Breaking long mathematical formulas or lines of dialogue naturally within a paragraph.
