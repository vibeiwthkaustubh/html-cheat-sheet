Code tag ("<code>"....."</code>") - [Both Opening & Closing tags required]

Description:- The <code> tag is an inline semantic element used to display fragments of computer programming code, commands, or file names. Browsers render the text inside <code> in a default monospace font (such as Courier or Consolas).

Standards & Discontinued Alternatives Note:
  • Discontinued <xmp>, <listing>, and <plaintext>: In very early HTML, tags like <xmp> were used to display raw code without escaping angle brackets. They were discontinued and removed in HTML5 because they violated standard DOM parsing rules.
  • Modern Standard Replacement: Use <pre><code> together, and escape angle brackets (&lt; for < and &gt; for >).
  • <code> vs <pre>: <code> is inline and does not preserve indentation or newlines. <pre> is a block element that preserves whitespace. To display a multi-line code snippet, always nest <code> inside <pre>.
  • Related Semantic Tags: Use <kbd> for user keyboard inputs, <samp> for program output, and <var> for mathematical or programming variables.

Example:- See the difference between an inline code snippet and a preformatted code block:

1. Inline Code Example:
To print output in JavaScript, you can use the console.log("Hello World!"); method.

2. Multi-line Code Block (<pre><code>): 

function calculateArea(width, height) {
 // Returns area of rectangle
 return width * height;
}

Attributes:-

  • Global Attributes :- Supports all global attributes such as class, id, and style.
  • Class for Syntax Highlighters :- Commonly given classes like class="language-javascript" or class="language-html" so JavaScript syntax highlighting libraries (like Prism.js or Highlight.js) can colorize the code.

Use cases:-

  • Displaying inline function names, variables, keywords, and terminal commands in technical documentation.
  • Creating multi-line code blocks when nested inside <pre>.
  • Referencing filenames, HTML tags, or CSS properties inside tutorial paragraphs.
  • Integrating with modern syntax highlighting libraries.
