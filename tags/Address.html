Address tag (<address>.....</address>) - [Both Opening & Closing tags required]

Description:- The <address> tag is a semantic HTML element used to mark up contact information for a person, author, or organization. Its main use cases are in footers, author sections, and contact pages, making websites more accessible and meaningful to both users and search engines.

Example:- Text displayed below are written inside the address tag . Also see the footer section, All the contact info and author's name is written inside the address tag.

Contact Me:
kaustubh@example.com
+91 9876543210
Bengaluru, Karnataka, India.

Use cases:-

  • Website Footer (Company Info)
  • Author Information in Articles
  • Personal Contact Section
