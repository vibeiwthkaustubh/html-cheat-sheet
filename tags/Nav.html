Nav tag ("<nav>"....."</nav>") - [Both Opening & Closing tags required]

Description:- The <nav> element represents a section of a page whose purpose is to provide navigation links, either within the current document or to other documents. Common examples include menus, tables of contents, and pagination.

Semantic Rule for <nav>:

Not ALL groups of links need to be wrapped in <nav>! It is intended specifically for major navigation blocks (e.g. main website menu, pagination, or documentation sidebars). Small lists of footer utility links (terms, privacy) typically just belong inside <footer> without a <nav>.

Example:- A semantic horizontal navigation bar:

  • Home
  • HTML Tutorials
  • Tags Cheat Sheet
  • Contact Kaustubh

Attributes:-

  • aria-label :- Recommended when multiple <nav> blocks exist on one page (e.g. aria-label="Main" vs aria-label="Footer").

Use cases:-

  • Main header website navigation menus.
  • Table of contents for lengthy technical guides.
  • Breadcrumb navigation and pagination controls.
