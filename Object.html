Object tag ("<object>"....."</object>") - [Both Opening & Closing tags required]

Description:- The <object> tag defines an embedded container for external resources, which can be treated as an image, a nested browsing context (like an HTML file), or a resource to be handled by a plugin (like PDF or SVG).

Built-in Fallback Capability:

Unlike <embed> (which is empty/void), the <object> tag allows nested fallback text or fallback elements. If the browser cannot display the resource specified in data, it automatically renders the inner fallback content!

Example:- Embedding vector SVG content with interactive fallback:

Key Attributes:-

  • data :- The URL address of the resource.
  • type :- The MIME type of the resource (e.g. application/pdf, image/svg+xml).
  • width & height :- Dimensions of the object container.
  • name :- Name of the object (can be targeted by links or forms).

Use cases:-

  • Embedding PDF documents with built-in fallback download links.
  • Embedding SVG graphics with inline fallback image alternatives.
