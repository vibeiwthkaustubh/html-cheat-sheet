Main tag ("<main>"....."</main>") - [Both Opening & Closing tags required]

Description:- The <main> tag represents the dominant, unique content of the <body> of a document. Content that is repeated across multiple pages (such as logos, navigation links, copyright info, and search sidebars) must NOT be placed inside <main>.

Strict HTML5 Cardinal Rule:

A document must have no more than one visible <main> element! It directly enables assistive screen reader users to execute the "Skip to Main Content" landmark command, bypassing repeated site header navigation menus.

Example:- You are currently viewing content enclosed inside <main> right now:

Inside <main>

This entire article and tag cheat sheet explanation sits inside the document's central <main> tag.

Attributes:-

  • Global Attributes :- class, id, style, etc.

Use cases:-

  • Wrapping unique page content for accessibility landmark navigation.
  • Serving as the target for "Skip to main content" accessibility skip links.

Complete code for the Main tag section

<!doctype html>
<html lang="en">
 <body>
  <header>Site Navigation</header>

  <!-- Unique page content -->
  <main>
   <h1>Today's Top News</h1>
   <p>Unique story content...</p>
  </main>

  <footer>Copyright 2026</footer>
 </body>
</html>
