Hr tag ("<hr>") - [Void Tag / Self-Closing (No Closing tag required)]

Description:- The <hr> (Horizontal Rule) tag represents a thematic break between paragraph-level elements in an HTML page (such as a shift of topic in an essay, or a transition between scenes in a story). It is a void element and is rendered as a horizontal divider line by default.

Semantic Evolution & Discontinued Attributes:

In HTML4, <hr> was merely a visual presentation line with attributes like align, noshade, size, and width. In HTML5, all those attributes are obsolete. The <hr> is now a true semantic thematic break, and all visual styling (colors, gradients, thickness, dashes) must be done using modern CSS.

Attributes:-

  • Global Attributes :- class, id, style.
  • Obsolete Attributes :- align, noshade, size, width (all replaced by CSS).

Use cases:-

  • Scene transitions in stories or books.
  • Dividing chapters, topics, or distinct sections in articles.
  • Separating terms and conditions or disclaimers at the bottom of forms.
