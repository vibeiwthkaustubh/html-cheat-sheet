Bdo tag ("<bdo>"....."</bdo>") - [Both Opening & Closing tags required]

Description:- The <bdo> (Bi-Directional Override) tag is used to explicitly override the default text direction of the content inside it. It forces the text to display in a specified direction, either left-to-right (ltr) or right-to-left (rtl), ignoring the browser's default bidirectional algorithm.

Example:- See how the direction of the exact same sentence reverses when wrapped inside the bdo tag with dir="rtl":

Default text direction (LTR):
This text is displayed normally from left to right.

Overridden with <bdo dir="rtl">:
This text is displayed normally from left to right.

Attributes:-

  • dir (Required) :- Specifies the bidirectional override direction for the enclosed text:
    • rtl :- Right-to-left text direction.
    • ltr :- Left-to-right text direction.

Use cases:-

  • Displaying multilingual content where Right-to-Left (RTL) languages like Arabic, Hebrew, Urdu, or Persian are mixed with Left-to-Right (LTR) languages like English or Hindi.
  • Preventing phone numbers, email addresses, product codes, or serial numbers from flipping incorrectly inside RTL text paragraphs.
  • Creating visual text-reversal effects or mirror puzzle text on a webpage without using JavaScript.
