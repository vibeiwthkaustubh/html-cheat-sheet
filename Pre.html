Pre tag ("<pre>"....."</pre>") - [Both Opening & Closing tags required]

Description:- The <pre> (Preformatted Text) tag represents preformatted text which is to be presented exactly as written in the HTML file. The text is rendered in a monospace font, and whitespace (both spaces and line breaks) is fully preserved exactly as authored.

Whitespace Collapsing in HTML vs <pre>:

Normally, HTML collapses multiple spaces, tabs, and newlines into a single space. Inside <pre>, the browser preserves every space, tab indentation, and newline. To make preformatted text responsive so it does not overflow horizontally, add the CSS rule: pre { overflow-x: auto; white-space: pre-wrap; }.

Example:- Preformatted poetry and ASCII diagram preserving spaces:

  /\_/\ 
 ( o.o ) <-- This ASCII cat preserves exact spaces
  > ^ <    because it is written inside a <pre> tag!

Attributes:-

  • width (Obsolete) :- In HTML4, width specified max character count per line. Discontinued in HTML5; use CSS.

Use cases:-

  • Displaying multi-line programming code (wrapped with <pre><code>).
  • Displaying terminal and command prompt logs.
  • ASCII art, musical tablature, and visual alignment diagrams.
