Select tags ("<select>", "<optgroup>", "<option>") - [Both Opening & Closing tags required]

Description:- The <select> element is used to create a drop-down selection menu in forms. It contains <option> elements representing selectable choices. The <optgroup> element allows grouping related options under bold, non-selectable category headers.

Multi-select & Disabled Categories:

Adding the multiple attribute to <select> lets users select multiple items holding Ctrl or Shift. You can also disable an entire group of choices instantly by adding <optgroup label="..." disabled>!

Example:- Grouped dropdown menu with <optgroup>:



Key Attributes:-

  • <select> :- name, required, multiple, size.
  • <optgroup> :- label (Required) (category title), disabled.
  • <option> :- value (sent to server), selected, disabled.

Use cases:-

  • Country and state pickers.
  • Category selectors in e-commerce filters.
  • Account role and permission selectors.
