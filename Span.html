Span tag ("<span>"....."</span>") - [Both Opening & Closing tags required]

Description:- The <span> tag is a generic inline container for phrasing content with no inherent semantic meaning. Just like <div> is used for block-level styling hooks, <span> is used for inline styling hooks without introducing a line break.

Semantic Alternatives Note:

Before reaching for <span>, check if a semantic inline tag applies:
• Strong importance? Use <strong>.
• Stress emphasis? Use <em>.
• Code fragment? Use <code>.
• Work citation? Use <cite>.
• Relevancy highlight? Use <mark>.
Use <span> purely for custom styling classes (badges, pill tags, colored words).

Example:- Inline styling with badges and custom color spans:

Order #1042 Status: Shipped

Order #1043 Status: Pending Review

Current Deal Price: $19.99 (Save 50%)

Attributes:-

  • Global Attributes :- class, id, style.

Use cases:-

  • Styling specific words or characters in a paragraph with CSS.
  • Creating inline badges, tags, chips, and counters.
  • Dynamic text insertion targets for JavaScript.
