Input tag ("<input>") - [Void Tag / Self-Closing (No Closing tag required)]

Description:- The <input> tag is one of the most powerful and versatile elements in HTML. It is an empty/void element used to create interactive controls for web-based forms to accept data from the user. How an <input> behaves and looks depends entirely on its type attribute.

HTML5 Mobile Validation & Virtual Keyboard Magic:

HTML5 introduced specialized input types like email, tel, number, and url. When viewed on smartphones and tablets, browsers automatically display the correct virtual keyboard (e.g. numeric keypad for number and tel, @ and .com keys for email) and provide automatic native regex validation without writing JavaScript!

Key Input Attributes:-

  • type :- Determines input behavior (text, email, password, file, date, etc.).
  • placeholder :- Short hint displayed in input before value is entered.
  • required :- Makes input mandatory before form submission.
  • value :- Initial or submitted value.
  • disabled & readonly :- Disables editing.
  • min, max, step :- Boundary rules for numbers, dates, and ranges.
  • pattern :- Regex rule for custom validation.

Use cases:-

  • Authentication forms (login, sign-up, password reset).
  • Data entry, search engines, e-commerce checkouts, and surveys.
