Section tag ("<section>"....."</section>") - [Both Opening & Closing tags required]

Description:- The <section> tag represents a standalone generic thematic grouping of content, which doesn't have a more specific semantic element (like <article>, <aside>, or <nav>) to represent it. By HTML5 specification guidelines, a <section> should almost always have a heading (<h2> - <h6>) identifying its theme.

<section> vs <article> vs <div>:

• <article>: Content is completely self-contained and independently distributable (e.g. a blog post, news story, comment).
• <section>: A thematic chapter or subsection of a larger document.
• <div>: Non-semantic container used purely for CSS visual layout.

Example:- Thematic sections with headings:

Section 1: About the Author

Kaustubh Singh is a passionate web developer creating educational HTML5 and web technology resources.

Section 2: Course Curriculum

Covering everything from basic semantic elements to advanced forms, multimedia, and accessible web architecture.

Attributes:-

  • Global Attributes :- class, id, style, etc.

Use cases:-

  • Chapters of a long story or documentation book.
  • Thematic tabs/panes on a product landing page (Features, Pricing, FAQs).
