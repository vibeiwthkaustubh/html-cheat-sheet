Embed tag ("<embed>") - [Void Tag / Self-Closing (No Closing tag required)]

Description:- The <embed> tag is a void (self-closing) element used as an integration point for an external resource, typically a third-party plugin, interactive application, or media viewer (such as an embedded PDF document, SVG graphic, or audio/video stream).

Standards & Discontinued Alternatives Note:

In older HTML, tags like <applet> were used to embed Java applications. <applet> is obsolete and discontinued in HTML5.
Modern Standards Comparison:
• For audio and video: Prefer the native <audio> and <video> elements.
• For other HTML pages: Prefer <iframe>.
• For interactive fallback objects: Prefer <object>.
• Use <embed> for raw embedded PDF documents or external application integration.

Example:- Embedding a vector SVG animation or document:

Attributes:-

  • src (Required) :- The URL of the resource being embedded.
  • type :- The MIME type of the embedded resource (e.g. application/pdf, image/svg+xml).
  • width & height :- Display dimensions in CSS pixels.

Use cases:-

  • Embedding PDF documents directly into web pages.
  • Integrating legacy media formats where specific browser plugins are used.
