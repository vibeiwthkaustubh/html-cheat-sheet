List tags ("<ul>", "<ol>", "<li>") - [Both Opening & Closing tags required]

Description:- HTML provides two primary types of lists: <ul> (Unordered List) for bulleted items where order does not matter, and <ol> (Ordered List) for numbered items where sequence is significant. Every list item inside them is wrapped in an <li> tag.

Discontinued HTML4 Attributes vs Modern CSS:

In HTML4, attributes like <ul type="disc|square|circle"> and <ol type="1|a|A|i|I"> were used. In HTML5, list bullet/number styles should be customized using the CSS property list-style-type. Attributes like start and reversed on <ol> remain fully supported and standard in HTML5.

Example:- Unordered vs Ordered Lists:

Unordered (<ul>)

  • HTML5 Semantic Tags
  • CSS3 Flexbox and Grid
  • JavaScript ES6+

Ordered (<ol>)

  1. Plan page layout
  2. Write semantic HTML
  3. Style with responsive CSS
  4. Deploy to GitHub

Key Attributes on <ol>:-

  • start :- Specifies the starting number for the list (e.g. start="5").
  • reversed :- Boolean attribute that numbers list items in descending reverse order.

Use cases:-

  • Navigation menus (typically <nav><ul><li>).
  • Step-by-step recipes, algorithms, and tutorial directions (ordered lists).
  • Feature bullet points on product landing pages.
