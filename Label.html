Label tag ("<label>"....."</label>") - [Both Opening & Closing tags required]

Description:- The <label> tag represents a user-friendly caption for a form control. It can be linked to a control either using the for attribute (matching the input's id) or by wrapping the <input> directly inside the <label>.

Two Huge Usability Advantages:

1. Enlarged Click/Tap Target: Clicking the text inside a <label> automatically focuses the text input or toggles the checkbox/radio button! This is massive on mobile screens where small checkboxes are hard to tap.
2. Screen Reader Announcement: Assistive screen readers announce the label text aloud the instant a blind user focuses on an input control.

Example:- Try clicking the text label to toggle the checkbox and focus input:


Attributes:-

  • for :- Specifies the id of the form element the label is bound to.

Use cases:-

  • Accessible input captions on all forms.
  • Increasing checkbox and radio button tap targets on touchscreens.
