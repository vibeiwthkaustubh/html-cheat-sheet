Fieldset & Legend tags ("<fieldset>", "<legend>") - [Both Opening & Closing tags required]

Description:- The <fieldset> tag is used to group several related form controls and labels within an HTML form. The <legend> tag represents a caption or title for the parent <fieldset>, rendered directly on the fieldset's top border.

Accessibility Superpower:

Screen readers announce the <legend> text whenever a user navigates into any input field inside that fieldset. This is critical for radio button groups and multi-step forms so users always know the context of the question they are answering.
Bonus: Setting <fieldset disabled> automatically disables every input, button, and select inside it at once!

Attributes:-

  • disabled :- Disables all descendant form controls at once.
  • form :- Links fieldset to a <form> by ID even if placed outside it.
  • name :- Name associated with the fieldset group.

Use cases:-

  • Grouping radio buttons for a single question.
  • Organizing shipping vs billing address sections in checkout flows.
  • Disabling entire sections of a form during processing or conditional steps.
