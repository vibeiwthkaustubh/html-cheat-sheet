Data tag ("<data>"....."</data>") - [Both Opening & Closing tags required]

Description:- The <data> tag links a given piece of visible content with a machine-readable translation. It allows human-readable text to be displayed normally on the screen while associating an underlying machine-readable value (like a product SKU, barcode, or database ID) via its value attribute.

<data> vs <time> Standards Note:

If the data you are representing is date- or time-related (such as publishing dates, timestamps, or durations), the W3C/WHATWG specification requires using the semantic <time datetime="..."> element instead of <data>. Reserve <data> strictly for non-temporal values (product IDs, part numbers, ISBN numbers, prices, or coordinates).

Example:- An e-commerce product catalog displaying user-friendly names while embedding underlying machine-readable product item codes:

  • Wireless Noise-Canceling Headphones (Inspect element to see value="SKU-8921")
  • Mechanical RGB Gaming Keyboard (Inspect element to see value="SKU-4412")
  • Ultra HD 4K Monitor (Inspect element to see value="SKU-9903")

Attributes:-

  • value (Required) :- Specifies the machine-readable value of the element.
  • Global Attributes :- Supports all global HTML attributes such as class, id, title, and Microdata attributes like itemprop.

Use cases:-

  • Binding product SKUs, inventory counts, or barcode numbers in online store listings.
  • Providing machine-readable data for web scrapers, automated crawlers, and search indexing bots.
  • Exposing structured dataset values to client-side JavaScript without altering visual text.
