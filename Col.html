Col tag ("<col>") - [Void Tag / Self-Closing (No Closing tag required)]

Description:- The <col> tag is used to specify column properties for each column within a <colgroup> element inside a table. It allows you to apply styling (like background color or column width) to an entire column rather than repeating styles for every single table cell.

Standards & Discontinued Attributes Note:

In HTML4, <col align="center" width="100"> was used to align text and set column widths. In HTML5, attributes like align, valign, and char are obsolete.
Modern Alternative: Style columns using modern CSS classes or CSS properties (e.g. background-color, width, visibility) applied directly to the <col> tag.

Example:- In the table below, the first column is highlighted with a soft blue background and the second with a yellow tint using <col>:

Student Name Roll No Marks
Kaustubh Singh 101 95%
Aman Verma 102 88%

Attributes:-

  • span :- Specifies the number of consecutive columns the <col> element should apply its properties to (default is 1).
  • style / class :- Applies CSS styling (background-color, width, border) to the entire span of columns.

Use cases:-

  • Highlighting specific columns (like row headers, totals, or IDs) in financial tables.
  • Setting uniform column widths across large data tables without styling individual <td> cells.
  • Hiding or collapsing columns dynamically with visibility: collapse.
