Form tag ("<form>"....."</form>") - [Both Opening & Closing tags required]

Description:- The <form> tag is used to create an HTML form for user input. It acts as a container for interactive controls (inputs, checkboxes, radio buttons, file uploads, textareas, and submit buttons), packing their data and sending it to a web server for processing.

Deep Dive: Understanding the enctype Attribute (Form Encoding Types):

The enctype attribute specifies how form data is encoded before sending it to the server (only works when method="POST"):

enctype Value When to Use It How Data is Encoded
application/x-www-form-urlencoded (Default) Standard text forms (login, sign up, contact). All characters are encoded (spaces become +, special symbols converted to ASCII HEX).
multipart/form-data (CRITICAL) Forms that upload files, images, or binary data (<input type="file">). No characters are encoded. Data is split into separate parts with boundaries so the server can reconstruct files. Without this, file uploads will fail!
text/plain Debugging or sending raw email forms via mailto:. Spaces converted to +, but no special characters are encoded. (Rarely used in production).

Key Form Attributes:-

  • action :- The server endpoint URL where form data is sent upon submission.
  • method :- HTTP method used: POST (secure, sends data in request body) or GET (appends data to URL query string).
  • enctype :- Specifies data encoding: application/x-www-form-urlencoded, multipart/form-data, or text/plain.
  • target :- Where to display response: _self, _blank.
  • autocomplete :- on or off for browser form autofill.
  • novalidate :- Bypasses browser client-side HTML5 validation when submitting.

Use cases:-

  • User registration, login, and authentication flows.
  • Uploading resumes, profile photos, and documents via multipart/form-data.
  • Search bars and contact forms.
