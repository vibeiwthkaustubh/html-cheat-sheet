Table tag ("<table>"....."</table>") - [Both Opening & Closing tags required]

Description:- The <table> tag represents tabular data: information presented in a two-dimensional matrix of rows and columns. A fully accessible semantic table comprises <thead> (header rows), <tbody> (body rows), <tfoot> (footer/totals), <tr> (table row), <th> (header cell), and <td> (standard data cell).

Strict Modern Standard Rule: Never Use Tables for Page Layout!

In the 1990s and early 2000s, websites used invisible tables for positioning page layout. In modern HTML5, tables must strictly be used ONLY for tabular data. For page layout, always use CSS Flexbox and CSS Grid.

Example:- Complete semantic tabular data report:

Product Quantity Unit Price Total
Mechanical Keyboard 2 $75.00 $150.00
Optical Mouse 1 $45.00 $45.00
Grand Total $195.00

Key Table Attributes & Elements:-

  • colspan & rowspan :- Merges multiple columns or rows into a single cell.
  • scope :- Added to <th scope="col|row"> for screen reader column/row mapping.

Use cases:-

  • Invoices, receipts, financial ledgers, and order summaries.
  • Sports leaderboards, timetables, and train schedules.
