Audio tag (<audio>.....</audio>) - [Both Opening & Closing tags required]

Description:- The <audio> element represents audio playback in HTML. It provides a semantic way to include audio files without relying on external plugins. It supports multiple formats like MP3, OGG, and WAV.

Example:- This audio was added in this web page using the audio tag.

Attributes:-

  • controls :- Adds standard audio playback controls such as play, pause, seek bar, and volume.
  • src :- Specifies the file path or URL of the audio source to be played.
  • loop :- Specifies that the audio track will restart automatically each time it finishes.
  • preload :- Hints how the browser should pre-buffer the audio file (none, metadata, or auto).
  • autoplay :- Causes the audio to begin playing automatically as soon as it is ready.
  • muted :- Sets the audio output to muted by default.

Use cases:-

  • Playing music tracks, podcasts, and radio broadcasts online.
  • Adding interactive sound effects for UI clicks, notifications, and games.
  • Pronunciation guides for online dictionaries and e-learning platforms.
  • Providing accessibility audio descriptions or spoken text for visually impaired users.
