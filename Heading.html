Heading tags ("<h1>" to "<h6>") - [Both Opening & Closing tags required]

Description:- The <h1> through <h6> elements represent six levels of section headings. <h1> is the highest (most important) level, and <h6> is the lowest. They structure the outline and semantic hierarchy of a webpage.

Critical SEO & Accessibility Rules:

• Only ONE <h1> per page: A webpage should have exactly one <h1> that represents the main topic of the entire page.
• Never skip heading levels: Always go from <h1> to <h2> to <h3>. Don't jump from <h1> directly to <h4> just to make text smaller; use CSS for font sizes!
• Screen readers use heading hierarchies like an audible table of contents so users can jump between sections.

Example:- Visual hierarchy of all six heading levels:

H1 Heading - Main Title

H2 Heading - Major Section

H3 Heading - Sub-Section

H4 Heading - Minor Topic

H5 Heading - Granular Item
H6 Heading - Lowest Level Heading

Attributes:-

  • Global Attributes :- class, id, style, etc.
  • align (Obsolete) :- In HTML4, align="center" was common. It is deprecated in HTML5; use CSS text-align: center; instead.

Use cases:-

  • Building an accessible table of contents and document outline.
  • Search engine indexing and SEO ranking.
