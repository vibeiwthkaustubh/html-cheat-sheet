Dfn tag ("<dfn>"....."</dfn>") - [Both Opening & Closing tags required]

Description:- The <dfn> (Definition) tag is used to mark the defining instance of a term within a document. When a term is first introduced and explained in a paragraph, wrapping it in <dfn> informs browsers and search engines that this specific sentence defines that term.

Semantic Rule:

The nearest parent sentence, paragraph, or definition group containing the <dfn> is considered the official definition of that term. The title attribute can also be added to <dfn> to provide an explicit tooltip definition.

Example:- Defining a term upon its first mention in an article:

An Internet Browser is a software application used to access and view websites across the globe.

Attributes:-

  • title :- Defines the exact term being defined, useful if different from the inner text.

Use cases:-

  • Glossaries, research papers, and educational tutorials introducing specialized terms.
  • Enabling automatic dictionary tooltips and cross-referencing indexes.
