Aside tag (<aside>.....</aside>) - [Both Opening & Closing tags required]

Description:- Newly introduced in HTML5 , used to represent information related to web page or article.

Example:- Here the (Did you know) section was written inside the aside tag which later with the help of the css can be placed accordingly.

Why Bees Matter

Bees pollinate roughly a third of the crops humans eat.

Without bees, food production would decline drastically.

Did You Know?

Honeybees can recognize human faces!

Use cases:-

  • Navigation menus, related posts, or widgets that sit beside the main article.
  • Displaying a notable quote or fact that complements the article.
  • Tangential promotional content that doesn't interrupt the main text.
  • Author Bio / Profile
