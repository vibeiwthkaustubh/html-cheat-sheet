## Key Features

- **60 Comprehensive Tag Pages**: From `<abbr>` to `<video>`, each tag features real-world examples, attributes, paired vs void tag indicators, and full source code.
- **Interactive Quick-Navigation Dropdown**: Switch directly between all 60 tags from any page without returning to the home index.
- **1-Click Copy Code**: Floating copy button on every code snippet with instant `Copied! [OK]` clipboard feedback.
- **Keyboard Arrow Navigation**: Navigate sequentially through tags using the `Left Arrow` (<-) and `Right Arrow` (->) keys.
- **Dark Matrix & Light Paper Themes**: Theme toggle with saved user preference in `localStorage`.
- **Real-Time Instant Search**: Filter tags dynamically on the homepage by syntax, keyword, or category (Press `/` to search).
- **Category Filter Pills**: Quickly filter tags by Semantic, Forms, Text, Media, Tables, or Metadata.
- **100% Responsive & Cross-Browser**: Designed with modern CSS Grid, Flexbox, and Glassmorphism.
