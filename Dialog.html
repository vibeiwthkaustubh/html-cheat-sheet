Dialog tag ("<dialog>"....."</dialog>") - [Both Opening & Closing tags required]

Description:- The <dialog> tag defines a native modal or non-modal dialog box / popup window. It represents a part of an application that a user interacts with to perform a task or receive information, complete with built-in accessibility and native backdrop dimming.

Modern HTML5 Feature: Replaces Custom JavaScript Modal Divs!

Historically, developers had to construct complex <div class="modal"> structures, trap keyboard focus manually, and write tricky backdrop overlay CSS. The <dialog> element provides showModal(), native focus trapping, the Esc key dismiss, and the ::backdrop pseudo-element automatically!

Example:- Click the button below to open a native HTML5 modal dialog:

Native HTML5 Modal

This dialog was opened using the native showModal() method!

Press Esc or click the button below to close it.

Attributes & Methods:-

  • open :- Boolean attribute that renders the dialog visible as a non-modal box.
  • showModal() :- JavaScript method that opens the dialog as a true modal with focus trap and backdrop.
  • close() :- JavaScript method that closes the dialog.

Use cases:-

  • Confirmation prompts (e.g. "Are you sure you want to delete this?").
  • Alert popups, login forms, and newsletter subscription boxes.
