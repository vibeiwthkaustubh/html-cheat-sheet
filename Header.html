Header tag ("<header>"....."</header>") - [Both Opening & Closing tags required]

Description:- The <header> element represents introductory content or a set of navigational links for a page or section. It typically contains one or more heading elements (<h1> - <h6>), a logo or icon, search forms, or author information.

<header> vs <head> vs <h1> Distinction:

• <head>: Invisible container for metadata, styles, and titles inside <html>.
• <header>: Visible semantic introductory container rendered inside <body>.
• <h1>: The primary heading text element.
