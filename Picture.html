Picture tag ("<picture>"....."</picture>") - [Both Opening & Closing tags required]

Description:- The <picture> tag is a modern responsive image container that gives web developers flexibility in specifying image resources. It contains one or more <source> elements with media queries and format types, followed by a mandatory fallback <img> tag.

Two Revolutionary Superpowers of <picture>:

1. Next-Gen Image Formats (AVIF / WebP): You can serve modern lightweight image formats to browsers that support them, while automatically falling back to standard JPEG/PNG for older browsers.
2. Art Direction: You can serve completely different cropped images based on viewport width (e.g. wide panoramic image on desktop, tight square close-up on mobile smartphones).

Example:- Responsive multi-source image container:

Browser intelligently chooses best source.

Elements Inside <picture>:-

  • <source> :- Uses srcset, media (media queries), and type (e.g. image/avif, image/webp).
  • <img> (Mandatory) :- The fallback image that actually renders the layout and holds the alt text.

Use cases:-

  • Serving AVIF/WebP image formats with JPEG fallbacks.
  • Art direction cropping between mobile and desktop layouts.

 <picture>
  <!-- Serve next-gen AVIF if supported -->
  <source srcset="hero.avif" type="image/avif" />
  <!-- Else WebP -->
  <source srcset="hero.webp" type="image/webp" />
  <!-- Fallback JPEG -->
  <img src="hero.jpg" alt="Hero banner" />
 </picture>
</main>
