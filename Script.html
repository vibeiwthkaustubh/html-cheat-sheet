Script tag ("<script>"....."</script>") - [Both Opening & Closing tags required]

Description:- The <script> tag is used to embed executable code or data, most commonly client-side JavaScript. It can contain inline script statements or point to an external script file via the src attribute.

Performance Guide: defer vs async:

• Standard <script>: Blocks HTML parsing until downloaded and executed (slows page load).
• async: Downloads script in background asynchronously and executes it immediately when downloaded (best for independent ad/analytics scripts).
• defer (Best Practice): Downloads in background and executes only after HTML DOM parsing is completely finished, preserving script execution order!
• ES Modules: <script type="module"> enables ES6 import and export statements.

Key Attributes:-

  • src :- The URL or file path of an external script.
  • defer :- Defers execution until page parsing finishes.
  • async :- Executes script asynchronously when ready.
  • type="module" :- Enables modern ES Modules with strict mode.

Use cases:-

  • Adding interactive logic, forms handling, animations, and API calls.
  • Loading external libraries (e.g. React, chart libraries, analytics).
